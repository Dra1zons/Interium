# Сборка Interium без Jarvis и локальной установки Java

Это комплект ИСХОДНИКОВ для облачной сборки, НЕ готовый мод и НЕ подтверждение успешной компиляции.

1. Создай на GitHub новый **Private** репозиторий (например interium-private). Исходники/ресурсы не публикуй публично: права на Delta-ассеты окончательно не выяснены.
2. Распакуй Interium-cloud-build-kit.zip. Через Add file → Upload files загрузи **содержимое** архива в корень репозитория. Не загружай ZIP одним файлом и не создавай лишнюю папку-обёртку. В корне должны быть build.gradle, gradlew, src, libs, tools и .github/workflows/build.yml.
3. Открой Actions. Если GitHub предлагает включить Actions, подтверди. Выбери **Build Interium → Run workflow → Run workflow** на основной ветке.
4. После зелёного результата открой запуск → Artifacts → **Interium-JAR**. Распакуй скачанный артефакт: внутри должен быть обычный remapped .jar, без -sources. Этот JAR предназначен для Fabric 1.21.11; это не мод для клиента 1.16.5.
5. Если запуск красный, скачай **Interium-build-log** и прикрепи сюда. Если ошибка до шага сборки и артефакта нет, скопируй ошибку неудачного шага из интерфейса Actions. Полная сборка ещё не выполнялась; ошибки API/Mixin/Loom могут потребовать исправлений.
6. Успешная сборка не означает проверку в Minecraft. Перед использованием на сервере нужны запуск клиента и проверки TNT Timer, Free Camera и других модулей. Phase отсутствует.

В архиве нет большого vendor/ViaFabricPlus-4.4.15.jar: workflow сам загружает его из официального Modrinth и сверяет SHA-256 с оригинальным бинарником. Это позволяет загружать файлы через веб-интерфейс GitHub (его лимит 25 МБ на файл). Собранный мод по-прежнему включает ту же зависимость, как и исходный проект. API-JAR для компиляции сохранён в libs. Сторонние notices и ссылки на исходники сохранены.

Секреты, токены и доступ к твоему компьютеру не нужны. Workflow не публикует релизы и использует contents: read. Возможность запуска/лимиты GitHub Actions зависят от настроек и плана аккаунта. Пакет в этом чате подготовлен и локально проверен структурно; Actions ещё не запускался.
